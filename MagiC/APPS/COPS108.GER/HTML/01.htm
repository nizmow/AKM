Einleitung

COPS ist ein Server für Kontrollfelder (CPX-Module), die vielen modernen Programmpaketen beiliegen. COPS ersetzt das neueren TOS-Versionen beiliegende XCONTROL.ACC von ATARI.

COPS zeichnet sich durch folgende Eigenschaften aus:

  • Es können beliebig viele Kontrollfelder gleichzeitig geöffnet werden (solange das System Fenster zur Verfügung stellen kann).
     
  • COPS merkt sich die Position der einzelnen Kontrollfelder.
     
  • Es können auch Kontrollfelder mit größerer Arbeitsfläche benutzt werden - COPS paßt die Fenstergröße an das Resource an.
     
  • COPS unterstützt lange Dateinamen: Kontrollfelder können z.B. im Ordner "Kontrollfelder" abgelegt werden. Sowohl Ordner- als auch Dateinamen können Leerzeichen enthalten (z.B. "MagiC Konfiguration.cpx"). (*)
     
  • Geringer Speicherverbrauch.
     
  • COPS funktioniert auch auf 68040-Prozessoren (mit eingeschaltetem Copyback-Cache) oder Prozessoren mit großem Code- und Datencache (68k-Emulation auf PowerPC-Rechnern).
     

(*) Beachten Sie bitte, daß nicht jeder Desktop mit Leerzeichen im Dateinamen umgehen kann (mit MAGXDESK funktioniert es, mit der EASE nicht).
